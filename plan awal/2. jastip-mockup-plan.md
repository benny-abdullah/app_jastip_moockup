## 4. HALAMAN CUSTOMER

### P-C1 — Dashboard Customer
File: `pages/customer/dashboard.html`.
Section:
- Hero banner membersih
- Grid produk rekomendasi (card-stat)
- Status keanggotaan (badge tier + points + progress)
- Riwayat transaksi terakhir (table mini)
- CTA "Top Up Points" & "Beli Langganan"

### P-C2 — Katalog Produk
File: `pages/customer/products.html`.
Section:
- Search & filter (kategori, range harga, sort)
- Grid product card: foto produk, nama, harga poin, stok, btn "Beli" / "Detail"
- Badge "Bisa COD" untuk produk yang memenuhi syarat

### P-C3 — Detail Produk
File: `pages/customer/product-detail.html`.
Section: galeri foto (main + thumbnail), info produk (harga poin, stok, deskripsi),
pilih qty, tombol "Beli Sekarang" & "+ Keranjang", info pengiriman & estimasi.

### P-C4 — Keranjang & Checkout
File: `pages/customer/cart-checkout.html`.
Section: list item keranjang (qty +/−, hapus), ringkasan belanja (subtotal poin, ongkos kirim
poin, diskon member tier jika ada, total), form alamat & pilih Hub (dropdown, hanya Hub radius
≤10 km), tombol "Konfirmasi & Bayar".

### P-C5 — Rewards & Redeem
File: `pages/customer/rewards.html`.
Section: list rewards (judul, deskripsi, poin, stok) + tombol "Redeem".
Jika poin tidak cukup → tombol disabled + label "Poin tidak cukup".

### P-C6 — Subscription & Auto-Delivery
File: `pages/customer/subscription.html`.
Section: form langganan (pilih paket, alamat, frekuensi), tabel histori subscription, status badge aktif/nonaktif.

### P-C7 — Notifications
File: `pages/customer/notifications.html`.
Section: list notifikasi (icon kategori, judul, waktu, baca/belum), filter by kategori.

### P-C8 — Profile & Settings
File: `pages/customer/profile.html`.
Section: form data diri, alamat (termasuk radius ke Hub), preferensi notifikasi, tombol "Simpan Perubahan", tombol "Ganti Password".

### P-C9 — Checkout (Points Payment)
File: `pages/customer/checkout.html`.
Section: ringkasan pesanan, alamat pengiriman (dalam radius 10 km — pilih dari daftar Hub), gunakan poin (input jumlah), breakdown biaya, tombol "Konfirmasi & Bayar dengan Poin".

## Bagian 5 — HALAMAN ADMIN HUB

### P-H1 — Dashboard Admin Hub
File: `pages/hub/dashboard.html`.
Section: card-stat (Produk, Stok Menipis, Pesanan Masuk, Pendapatan), tabel pesanan terbaru, chart penjualan mini.

### P-H2 — Manajemen Produk Hub
File: `pages/hub/products.html`.
Section: table-produk (foto, nama, stok, harga poin, status aktif/nonaktif), form tambah/edit produk (modal), pencarian.

### P-H3 — Manajemen Stok
File: `pages/hub/stock.html`.
Section: card-stat (Total SKU, Stok Menipis, Stok Habis), tabel stok dengan kolom "Restock" inline, form restock (modal), riwayat mutasi stok.

### P-H4 — Verifikasi Pembayaran
File: `pages/hub/payment-verification.html`.
Section: list transaksi menunggu verifikasi, detail transaksi (modal), tombol "Verifikasi" & "Tolak" dengan alasan.

### P-H5 — Manajemen Pengiriman
File: `pages/hub/delivery-management.html`.
Section: tabel pesanan (ID, customer, alamat, radius_km, status), aksi assign kurir & update status, highlight status "Menunggu Kurir" jika belum ada kurir.

### P-H6 — Laporan Keuangan Hub
File: `pages/hub/finance-report.html`.
Section: card-stat (omzet, fee, pending), table transaksi, filter tanggal.

## ⚙️ AKSI YANG DIMINTA
Berdasarkan dokumen perencanaan di atas, buat **semua file HTML mockup** sesuai spesifikasi berikut:

1. **Semua halaman** dalam `pages/...` sesuai site map.
2. **Semua komponen** dalam `components/` sesuai daftar.
3. **Semua layout** dalam `layouts/`.
4. **Asset** minimal: logo.svg (placeholder sederhana) dan dummy data / mock data jika diperlukan.
