# Domain
Aplikasi Jastip adalah aplikasi erp untuk toko retail, seperti Alfagift atau klik Indomaret

## Fitur

 - Membership
 - Points
 - Payment
 - Customer Monthly Subscription
 - Warehousing
 - Pengiriman
 - Promo / Event
 - Single Item / Bundling Item
 - Pengaduan Customer by CS

### Points
Catatan:
 - Customer melakukan Top Up ke Admin
 - Exchange Rupiah ke Points
 - Digunakan Customer untuk bertransaksi

Points juga dapat di reedem untuk Reward, antara lain:
- Umrah
- Qurban

### Payment
Menggunakan Point 

### Subscription
Customer dapat berlangganan pembelian barang setiap bulannya

### Warehousing
Terdapat Warehouse Pusat dan Hub. Hub memiliki stok tersendiri dan dapat melakukan order stok. Hub juga sebagai pengirim pesanan Customer.

### Hub
- Mempunyai Warehousing
- Melakukan Stock Taking
- Bisa order stok ke Warehouse Pusat
- Memiliki Customer, Radius Based
