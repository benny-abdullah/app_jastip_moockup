Panduan Per Menu

Klik nama menu untuk langsung membuka halaman terkait. Setiap kartu berisi pengertian & langkah pengoperasian.

Dashboard (Beranda)

Buka

Halaman utama setelah login. Menampilkan ringkasan saldo points, tier membership, statistik pesanan, quick actions, dan aktivitas terbaru dalam satu tampilan.

Cara Pengoperasian
  1. Lihat banner sambutan untuk saldo & tier.
  2. Gunakan tombol aksi cepat (Belanja / Top Up / Reward / Lacak).
  3. Periksa 4 stat card untuk ringkasan pesanan.
  4. Gunakan tab Ringkasan / Pesanan / Aktivitas.

Katalog

Buka

Tempat melihat semua produk yang tersedia (16 kategori) dengan fitur pencarian, filter, dan urutan harga. Produk bisa dibeli dengan points.

Cara Pengoperasian
  1. Cari produk via kolom pencarian atau pilih kategori.
  2. Saring berdasarkan harga / rating / urutkan.
  3. Klik produk untuk melihat detail + qty.
  4. Klik tombol hati untuk menyimpan ke wishlist.

Keranjang

Buka

Menyimpan sementara produk yang akan dibeli. Anda dapat mengubah jumlah (qty), menghapus item, dan melihat subtotal sebelum melanjutkan checkout.

Cara Pengoperasian
  1. Periksa daftar produk + harga per item.
  2. Naik/turunkan qty atau klik hapus.
  3. Pastikan subtotal sudah sesuai.
  4. Klik Checkout untuk lanjut ke pembayaran.

Pesanan

Buka

Daftar riwayat semua pesanan — baik dari checkout biasa maupun dari paket member. Dilengkapi kolom sumber, status, dan tombol lacak pengiriman.

Cara Pengoperasian
  1. Filter sesuai status (Selesai/Dikirim/Diproses/Batal).
  2. Filter sumber: Belanja atau Paket Member.
  3. Cari dengan kata kunci order id / produk.
  4. Klik Lacak untuk melihat posisi paket.

Points & Top Up

Buka

Kelola saldo points untuk belanja. Top up via transfer bank dengan memilih nominal + upload bukti. **Poin tidak dapat ditukar uang tunai**.

Cara Pengoperasian
  1. Pilih nominal (50k/100k/250k) atau isi manual.
  2. Pilih bank tujuan → no rekening otomatis tampil.
  3. Upload bukti pembayaran (JPG/PNG).
  4. Klik Top Up Sekarang & tunggu verifikasi 1x24 jam.

Rewards

Buka

Klaim berbagai reward (voucher, produk, paket umroh, berqurban) dengan menukarkan points yang dimiliki.

Cara Pengoperasian
  1. Lihat katalog reward + biaya points.
  2. Periksa saldo points Anda cukup atau tidak.
  3. Klik Klaim → points otomatis terpotong.
  4. Reward diproses / dikirim sesuai ketentuan.

Subscription (Paket Member)

Buka

Berlangganan paket sembako berkala (Hemat/Keluarga/Premium) dengan auto-renewal. Setiap pilih paket otomatis masuk ke riwayat pesanan sebagai "Paket Member".

Cara Pengoperasian
  1. Pilih paket sesuai kebutuhan (75k / 114k / 200k pts).
  2. Klik Pilih Paket → status aktif.
  3. Tier dihitung otomatis (spend + durasi).
  4. Lihat riwayat siklus tagihan di bawah paket.

Komplain

Buka

Ajukan pengaduan terkait order apa pun (Belanja maupun Paket Member). Pilih order terlebih dahulu, lalu kategori & deskripsi.

Cara Pengoperasian
  1. Pilih pesanan dari dropdown (semua riwayat tersedia).
  2. Pilih kategori (Produk, Pengiriman, Pembayaran, dll).
  3. Isi subjek + deskripsi lengkap.
  4. Kirim → CS merespon dalam 1x24 jam via chat/email.

Profil & Tier

Buka

Lihat data profil dan level membership (Bronze, Silver, Gold, Platinum, Diamond) + progress otomatis berdasarkan total belanja & durasi berlangganan.

Cara Pengoperasian
  1. Baca badge tier aktif + masa berlaku.
  2. Lihat progress menuju tier berikutnya.
  3. Periksa tabel benefit per tier.
  4. Baca info skema upgrade otomatis (spend + tahun).

Wishlist

Buka

Simpan produk favorit agar mudah ditemukan lagi. Produk tersimpan otomatis dari ikon hati di katalog.

Cara Pengoperasian
  1. Di katalog, klik ikon hati pada produk.
  2. Buka halaman ini untuk melihat semua tersimpan.
  3. Klik hati lagi untuk hapus / tambah ke keranjang.

Review Produk

Buka

Beri rating dan ulasan terhadap produk dari order yang statusnya Selesai. Semua produk dari order Belanja maupun Paket Member bisa di-review.

Cara Pengoperasian
  1. Pilih produk dari daftar "pesanan selesai".
  2. Klik bintang 1–5 sesuai penilaian.
  3. Isi ulasan / pengalaman.
  4. Klik Kirim Review.

Preferensi Email

Buka

Atur jenis email yang ingin Anda terima: update pesanan, pembayaran, pengiriman, subscription, promo, dan notifikasi lainnya.

Cara Pengoperasian
  1. Nyalakan/matikan toggle sesuai preferensi.
  2. Perubahan tersimpan otomatis.
  3. Cek inbox untuk pengiriman uji.

Referral

Buka

Ajak teman bergabung dan dapatkan poin bonus (5.000 pts per teman, tanpa batas jumlah referral).

Cara Pengoperasian
  1. Tekan tombol Copy Link.
  2. Bagikan ke teman / medsos.
  3. Pantau jumlah referral & bonus poin.

Tips & Aturan Penting

Hal-hal yang perlu Anda pahami sebelum memaksimalkan dashboard customer.

Poin Tidak Tunai

Poin hanya dapat ditukar dengan barang / reward — tidak dapat diklaim menjadi uang tunai (non-cashable / non-withdrawable).

Upgrade Tier Otomatis

Tier naik otomatis dari total belanja (1jt → Silver, 5jt → Gold, dst) dan durasi berlangganan (1th, 3th, 5th).

Ongkir Sudah Termasuk

Biaya pengiriman tidak dihitung terpisah — semua sudah termasuk dalam harga produk (RAB).

Dua Sumber Pesanan

Riwayat pesanan menggabungkan order dari Belanja Checkout dan Paket Member. Perhatikan kolom sumber masing-masing.
